# text-to-speech-converter
A simple Text-to-Speech Converter using JavaScript SpeechSynthesis API with voice selection and clean UI.
#
## 🚀 Features
- Convert text into speech instantly  
- Voice selection from system/browser voices  
- Smooth and modern UI  
- No external libraries or frameworks  
- Works in all modern browsers

---

## 📁 Project Files  
- **index.html** – UI structure  
- **style.css** – Styling and layout  
- **script.js** – Speech synthesis logic  

---

## 🧠 How It Works
- Browser loads voices using `speechSynthesis.onvoiceschanged`
- Dropdown gets populated dynamically  
- When user clicks **Listen**, the text is spoken aloud  

---

## 📦 Technologies Used
- HTML5  
- CSS3  
- JavaScript (SpeechSynthesisUtterance API)
